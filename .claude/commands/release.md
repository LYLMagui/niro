# 版本发布

请执行以下步骤：

1. 读取 `docs/release.md` 了解当前版本
2. 根据以下规则确定新版本号：
   - Patch (0.0.x): Bug 修复
   - Minor (0.x.0): 新功能
   - Major (x.0.0): 架构重构

3. 更新 docs/release.md 记录本次变更
4. 使用以下格式：
   ```
   ## v{x}.{y}.{z} - {日期}

   ### 新增
   - {功能描述}

   ### 修复
   - {修复描述}

   ### 优化
   - {优化描述}
   ```
