# 记忆整理命令

> 基于老金三层记忆系统设计，支持自动记忆提取、归档、回顾分析

## 功能说明

此命令用于在会话中或会话结束时快速整理记忆，将关键信息保存到三层记忆系统。

## 命令选项

### 1. 查看记忆状态 `-s, --status`

显示当前记忆系统的完整状态面板：

```
+-----------------------------------------------------------+
| Layer 1: 知识图谱 (Knowledge Graph)                       |
+-----------------------------------------------------------+
|   总条目: XX   活跃: XX   已废弃: XX                      |
+--- 分类明细 ------------------------------------------------+
|   分类名: XX (XX活跃, XX废弃)                             |
+-----------------------------------------------------------+

+-----------------------------------------------------------+
| Layer 2: 每日笔记 (Daily Notes)                          |
+-----------------------------------------------------------+
|   笔记文件: XX                                            |
|   归档文件: XX                                            |
+-----------------------------------------------------------+

+-----------------------------------------------------------+
| Layer 3: MEMORY.md (长期记忆)                           |
+-----------------------------------------------------------+
|   行数: XX   tokens: ~XXX                                 |
|   章节: XX                                                |
|   最后更新: XXXX-XX-XX                                   |
+-----------------------------------------------------------+

+-----------------------------------------------------------+
| 系统指标 (System Metrics)                                 |
+-----------------------------------------------------------+
|   磁盘占用: XXX KB                                        |
|   启动Token估算: ~XXX tokens                             |
|   废弃比例: X% (状态: 健康/警告)                         |
+-----------------------------------------------------------+

+-----------------------------------------------------------+
| [诊断意见]                                                 |
+-----------------------------------------------------------+
|   - Layer 3 长期未更新提醒                               |
|   - Token 消耗评估                                       |
+-----------------------------------------------------------+
```

### 2. 记忆回顾分析 `-r, --review`

扫描知识图谱，生成分析报告：

```
+-----------------------------------------------------------+
| 统计概览                                                   |
+-----------------------------------------------------------+
|   Layer 1 记录: XX (活跃: XX, 废弃: XX)                  |
|   Layer 2 笔记: XX                                        |
|   Layer 3 规则: XX                                       |
+-----------------------------------------------------------+

+-----------------------------------------------------------+
| 高频模式 (出现 2 次以上)                                  |
+-----------------------------------------------------------+
|   [category] 分类名: XX                                  |
|   [keyword]  关键词: XX                                   |
+-----------------------------------------------------------+

+-----------------------------------------------------------+
| 趋势分析 (近 14 天 vs 更早)                              |
+-----------------------------------------------------------+
|   近期: XX  早期: XX (增长/下降: XX%)                    |
+-----------------------------------------------------------+

+-----------------------------------------------------------+
| 衰减模式 (曾经活跃，现在减少)                             |
+-----------------------------------------------------------+
|   模式名: 早期 XX -> 近期 XX                             |
+-----------------------------------------------------------+

+-----------------------------------------------------------+
| 数据质量问题                                              |
+-----------------------------------------------------------+
|   空事实: XX                                             |
|   重复事实: XX                                           |
+-----------------------------------------------------------+

+-----------------------------------------------------------+
| 建议规则 (可写入 MEMORY.md)                               |
+-----------------------------------------------------------+
|   - 建议将 '分类名' 作为核心分类                         |
+-----------------------------------------------------------+
```

### 3. 提取洞察到 MEMORY.md `-i, --insight`

```
/organize-memory -i "用户偏好TypeScript严格模式"
/organize-memory --insight "使用Python标准库实现"
```

将关键洞察保存到长期记忆。

### 4. 添加任务到 PROJECTS.md `-p, --project`

```
/organize-memory -p "记忆系统优化" "完善去重功能" "添加压缩功能"
```

### 5. 标记任务完成 `-c, --complete`

```
/organize-memory -c "记忆系统优化" "去重功能已实现"
```

### 6. 完整整理 `-a, --all`

```
/organize-memory -a
```

## 使用流程

### 会话开始
- 自动加载最近3天每日笔记
- 自动加载知识图谱活跃条目（每主题10条）
- 自动加载 MEMORY.md 前200行

### 会话中
- PostToolUse Hook 自动提取知识到 items.json
- 24小时内相同 fact+category 自动去重

### 会话结束 / 上下文压缩
- PreCompact Hook 自动保存会话状态
- 自动归档30天前日志为 tar.gz

### 定期回顾
- 使用 `-r` 分析高频模式
- 使用 `-s` 查看系统健康状态

## 文件结构

```
.claude/
├── hooks/
│   ├── memory_loader.py      # SessionStart: 加载记忆
│   ├── memory_extractor.py   # PostToolUse: 提取知识（去重）
│   ├── pre_compact.py        # PreCompact: 归档压缩
│   └── session_state.py       # 状态管理+迁移函数
├── memory/
│   ├── MEMORY.md             # Layer 3: 长期记忆
│   ├── PROJECTS.md           # 项目跟踪
│   ├── memory/
│   │   └── YYYY-MM-DD.md     # Layer 2: 每日笔记
│   └── archive/
│       └── YYYY-MM.tar.gz    # 归档压缩包
└── settings.local.json       # Hook 配置
```
