## 2026-03-07 下午：OCR 服务正式集成

### 完成内容

1. **创建 OCR 服务模块**：`niro-spider/spiders/ocr_service.py`
   - 监听 Redis 队列 `niro:tasks:ocr`
   - 从 `images/` 目录读取图片
   - 使用 PaddleOCR 识别 CS2 饰品信息（名称、价格、磨损）
   - 识别完成后通过 HTTP POST 回调后端

2. **配置项添加到 settings.py**：
   - `IMAGES_DIR`: 图片目录
   - `OCR_QUEUE_NAME`: 队列名称
   - `OCR_LANG`: 识别语言
   - `OCR_CALLBACK_TIMEOUT`: 回调超时

3. **更新 main.py**：
   - 支持三种运行模式：`dual` / `consumer` / `ocr`

### 使用方式

```bash
# 启动 OCR 服务
python main.py --mode ocr

# 发送测试任务
redis-cli RPUSH niro:tasks:ocr '{"taskId": 123, "imagePath": "test.png", "callbackUrl": "http://localhost:8080/api/ocr/callback"}'
```
