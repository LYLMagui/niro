# 订单列表增强功能实现计划

## 1. 后端功能增强 (niro-server)
### C5 SDK 完善
- 在 `C5TradeClient` 中新增 `getOrderDetail` 接口，对接 C5 订单查询。
- 新增 `C5OrderDetailRequest` 和 `C5OrderDetailResponse` 实体。

### 业务逻辑实现
- **排序支持**：在 `TradeOrderRecordServiceImpl.getOrderRecordPage` 中集成 MyBatis-Plus 的排序功能，支持按 `price`、`createTime`、`status` 排序。
- **详情查询**：在 `TradeOrderRecordService` 中新增 `getC5OrderDetail` 方法，调用 C5 SDK 获取实时订单状态。
- **订单删除**：新增 `deleteOrderRecord` 方法，执行逻辑删除（符合军规）。

### 接口暴露
- `TradeOrderController` 新增：
  - `GET /order/record/c5/detail/{orderId}`：获取 C5 订单详情。
  - `DELETE /order/record/{id}`：删除订单记录。
- 修改 `GET /order/record/page`：增加 `sortField` 和 `sortOrder` 参数。

## 2. 前端界面优化 (niro-client)
### API 封装
- `api/order.ts` 新增 `delete` 和 `getC5Detail` 方法。

### 列表展示增强
- **新增列**：在 `OrderRecord.vue` 的表格中增加“平台订单号”列和“操作”列。
- **排序交互**：在表格表头开启 `sorter` 功能，联动后端排序接口。
- **详情展示**：
  - 实现 `viewC5Detail` 方法，点击订单号或详情按钮时触发。
  - 使用 TDesign 的 `t-drawer`（侧边栏）展示 C5 订单的详细 JSON 数据或结构化信息。
- **删除功能**：集成 `t-popconfirm` 确认气泡，防止误删，点击后调用删除 API 并刷新列表。
