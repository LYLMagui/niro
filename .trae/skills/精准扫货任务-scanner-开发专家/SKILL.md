# 任务：Niro 扫货逻辑开发
## 核心 SOP：
1. **精度控制**：价格计算必须使用 `BigDecimal`。磨损值（Paintwear）对比必须严格闭区间。
2. **拟人化注入**：每当修改扫描逻辑，必须检查 `scanInterval` 和 `restPeriod` 是否被正确引用。严禁移除“工作 X 分钟，休息 Y 分钟”的逻辑。
3. **并发安全**：由于使用 JDK 21，涉及多任务调度时优先使用虚拟线程（Virtual Thread）池。
4. **自检**：检查 Cron 表达式是否会导致任务在非预期时间内高频启动。
