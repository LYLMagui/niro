# Python 开发规范 (Spider)

## 1. 角色边界
- **模块**：所有代码必须在 `niro-spider` 模块内。
- **依赖**：优先引入活跃第三方库，严禁重复造轮子。
- **注释**：符合 PEP 8 规范，类/函数/模块必须有清晰注释。

## 2. 集成与导入
- **原则**：加载完整生产级实现，禁止裁剪/降级。
- **导入**：禁止只导不用。关键启动点建议打印 `__file__` 验证路径。
- **模式**：把第三方库当做不可修改黑箱，只编写最小必要的胶水代码。

## 3. 业务规范
- **模型**：`models` 必须加注释说明字段含义。
- **输出**：代码中需标注哪些能力来自外部依赖。
- **结构**：参考企业级项目结构（config, spiders, storage, utils）。
