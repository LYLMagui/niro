# 项目背景
- 面向 Buff 饰品交易场景的自动化交易与数据采集系统
- 架构上采用“前端管理台 + 后端服务 + 爬虫引擎”分层
- 目标是以低延迟、可规模化的方式获取市场数据并执行策略化交易
# 业务领域
- 交易自动化 ：围绕饰品的快速扫描、价格判断、下单与记录
- 账号与风控管理 ：多账号策略、状态监控、失败熔断、风险隔离
- 商品与市场数据 ：商品元数据、价格历史、标签属性存储与检索
- 任务调度与执行 ：批量策略任务的定时/循环执行
# 业务方向
- 高并发交易执行 ：提高下单吞吐与任务并行度
- 风险可控的自动化 ：规避平台风控、稳定运行
- 数据驱动策略 ：通过价格与历史数据驱动决策
- 平台化运营 ：提供统一管理后台与策略配置能力
