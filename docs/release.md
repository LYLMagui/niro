# Release Notes

## v1.16.2 (2026-01-12)
- [优化] **项目开发规范体系深度重构与复用性增强**
  - **规范多维拆分**：将原有的庞杂规范解耦为“1个通用 + 3个端专用”的精简体系，显著提升 AI 模型对不同技术栈的响应精准度。
  - **基础设施透明化**：在各端规范中深度集成项目现有的公共组件、工具类（如 Java Assert、RedisUtil, Python Logger 等）及业务算法说明，实现跨会话的逻辑复用。
  - **规范资产保护**：严格保留并加固用户自定义的项目与设计准则，确保核心工程理念的一致性与连续性。

## v1.16.1 (2026-01-12)
- [功能] **分类抓取逻辑深度优化与 Redis 暂存机制实现**
  - **全维度标签提取**：突破原有限制，新增对印花胶囊、稀有度、品质等全维度标签的解析，彻底解决分类数据抓取不全的问题。
  - **分阶段暂存与入库**：优化 Redis 暂存逻辑，改为每完成一个一级分类即执行一次批量入库并清空缓冲区，显著提升了长时间运行下的数据安全性和内存利用率。
  - **接口参数校准**：修正了同步一级分类时的 API 参数，将 `category` 替换为正确的 `category_group`，确保获取到的商品数据严格符合类目定义。
  - **跨类目数据污染修复**：增加严格的 `type` 匹配校验，确保抓取特定分类（如匕首）时，不会因 API 返回的推荐位或广告位数据而混入其他武器（如手枪）的二级分类。
  - **父级关联修复**：修复了分类同步中 `parent_internal_name` 错误关联的问题，改为从商品自身的 `type` 标签中动态获取真实的父级分类，避免了逻辑错误。
  - **探测与清理**：利用临时探测工具完成对接口标签结构的实时探测，并按规范清理所有测试代码，确保生产环境纯净。

## v1.16.0 (2026-01-12)
- [功能] **ELK 日志采集与监控系统集成 (MVP)**
  - **资源深度调优**：针对 2G 内存环境，禁用 ES 和 Kibana 的高耗能插件（AI、机器学习、Fleet等），并严格限制堆内存占用。
  - **自动化数据链路**：通过 Filebeat 实现爬虫 JSON 日志的自动采集，并配置容器层面的日志滚动策略，防止磁盘空间溢出。
  - **日志格式标准化**：对接双输出模式（文本用于人工排查，JSON 用于结构化检索），支持模块、函数、行号及全局出口 IP 的全链路追踪。
  - **访问安全优化**：提供安全访问方案并优化公网访问配置，解决 400 Bad Request 等连接异常。

## v1.15.6 (2026-01-11)
- [功能] **扫描间隔时间范围功能**
  - **灵活频率配置**：支持设置扫描间隔的时间范围（最小值-最大值），并新增多维度时间单位选择（秒/分钟/小时/天）。
  - **风控安全升级**：引入随机间隔机制，在指定范围内动态选择扫描频率，有效降低被平台风控识别的风险。
  - **交互体验优化**：重构配置界面，将单一输入框升级为范围选择器，并增强表单验证逻辑。
