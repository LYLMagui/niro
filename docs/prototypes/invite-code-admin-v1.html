新建邀请码
创建单个邀请码，默认支持自动生成 code。一个邀请码只能被一个账号使用。
原型中支持管理员手填，也支持系统自动生成。
批量生成邀请码
用于活动批量发码。生成成功后，直接在弹窗中展示结果并支持一键复制邀请码或注册链接。
编辑邀请码
未使用的邀请码允许修改备注和过期时间；已使用的邀请码仅允许补充备注。
