# Niro Control 原型

本目录存放产品设计阶段的 HTML 高保真原型，每个原型都是自包含的单 HTML 文件，直接双击即可在浏览器中查看。

## 原型列表

| 文件 | 主题 | 说明 |
|------|------|------|
| `menu-redesign-v1.html` | 菜单重构 V1 | 把平台（C5/BUFF/悠悠）从菜单层级移到页面内 tab；统一页面骨架 |
| `invite-code-admin-v1.html` | 邀请码管理 V1 | 单页列表工具型后台原型，包含筛选、表格、批量生成弹窗与注册信息抽屉 |

## 查看方式

直接在文件管理器中双击 HTML 文件即可。原型使用 Tailwind Play CDN，需要联网。

## 约定

- 单文件自包含，不依赖 build 工具
- 视觉参照 TDesign 规范（主色 `#0052D9`）
- 交互仅做"可演示"级别，真实逻辑走 Vue 实现
