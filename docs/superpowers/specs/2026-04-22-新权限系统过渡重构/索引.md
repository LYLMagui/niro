# 新权限系统过渡重构索引

## 主题
在保留旧权限系统的前提下，新增一套独立运行的新权限系统，用于承接新的路由装配方式、权限资源模型和权限管理页面，并通过 `new` 页面/菜单组与 `v2` 接口完成并行过渡。

## 当前状态
设计中，已确认方案。

## 当前有效结论
- 旧权限系统继续保留，不能原地替换。
- 新权限系统独立存在，前端相关页面、组命名统一加 `new`，接口统一使用 `v2`。
- 并行阶段复用旧系统的用户、角色；新建菜单、按钮、授权关系与发布态。
- 新路由系统采用混合模式：前端维护页面注册表，后端维护新菜单配置与新权限资源，前端按已发布配置装配最终导航。
- 新资源模型采用“路由/菜单绑定 + 按钮独立”：页面路由定义不在权限页内直接编辑，菜单负责导航展示配置，按钮权限独立建模但按页面聚合展示。
- 新权限管理页采用资源工作台结构：左侧资源树、中间资源配置、右侧角色授权，并通过抽屉承接用户分配和权限预览。
- 新权限系统一期采用分阶段试点：先迁移权限相关页面，再逐步迁移业务模块。
- 一期试点页确定为 `InviteCodeManageNew` 与 `LogsNew`，并通过侧栏新增 `new` 菜单组进入，旧入口保持不变。
- 权限变更采用“保存并发布”机制，不走即时生效；发布前需要做资源合法性校验，并支持按角色预览。
