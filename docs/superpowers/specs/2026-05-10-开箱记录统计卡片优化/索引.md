# 开箱记录页面统计卡片优化方案

作为产品经理，我建议对现有的统计卡片进行“高级感”重塑，使其不仅展示数据，更能直观地传达盈利/亏损的情绪价值，并提升整体 UI 的质感。

## 1. 视觉设计升级 (Visual Overhaul)
- **精致紧凑 (Compact Layout)**: 减小卡片的内边距和整体尺寸，使其更加精致，为下方的表格留出更多首屏空间。
- **玻璃拟态 (Glassmorphism)**: 引入 `backdrop-blur` 和半透明背景，配合极其微妙的渐变，打造通透感。
- **色彩情绪**: 
  - 盈利状态使用更加鲜活的 **Emerald** 绿，并带有微光效果。
  - 亏损状态使用柔和的 **Rose** 红，避免给用户过于沉重的压迫感。
- **动态图标**: 背景图标尺寸调小，从静态 SVG 升级为带微弱呼吸感或位移的动态效果。

## 2. 内容增强 (Content Enrichment)
- **引入利润率 (ROI)**: 在“预期总利润”卡片中，显著展示利润率。利润率是衡量开箱效率的核心指标。

## 3. 交互优化 (Interaction)
- **磁贴悬停**: 鼠标悬停时，卡片产生轻微的位移（Y轴偏移）和阴影加深。
- **点击下钻 (可选)**: 点击卡片可快速筛选下方列表。

---

## 详细修改计划

### 步骤 1: 压缩与增强基础样式
修改 `UnboxRecord.vue` 中的样式类，减小 `padding` 和图标尺寸，引入更高级的阴影和背景处理。

### 步骤 2: 优化“预期总利润”卡片
- 合并利润额与利润率。
- 强化正负状态的视觉对比。

### 步骤 3: 润色微动效
利用 CSS Transition 优化悬停体验。
