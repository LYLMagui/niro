# 变更记录

## 2026-05-09

### 变更内容

确认 C5 SDK 请求日志改造方案：底层 HTTP 客户端切换为 OkHttp，引入 `okhttp-logging-interceptor`，默认日志走自定义 C5 SDK 日志摘要拦截器，并通过 logback 将 `com.niro.sdk.c5` 日志独立分流。

### 原因

当前 C5 SDK 请求日志与业务日志混在 root logger 中，入参和响应展示不直观，生产排查时难以区分业务日志和 SDK 外部请求日志。

### 影响范围

- `niro-server/niro-sdk` 的 C5 HTTP 执行器与依赖。
- `niro-server/niro-web` 的 logback 配置。
- 不改变 C5 SDK 对外调用方法签名。

### 落地结果

- `niro-sdk` 已引入 OkHttp 与 `okhttp-logging-interceptor`。
- `C5HttpExecutor` 已从 JDK `HttpClient` 切换为 OkHttp。
- 默认生产日志走 C5 SDK 安全摘要日志；官方 OkHttp logging-interceptor 仅在 DEBUG logger 生效时输出 BASIC 级调试日志，并对敏感 query 参数二次脱敏。
- `com.niro.sdk.c5` 已独立输出到 `c5-sdk` 文件日志，避免 SDK 请求日志和业务日志混在同一文件。
- 已通过 `mvn -f "D:/MySpace/niro/niro-server/pom.xml" -pl niro-web -am compile -DskipTests -Dmaven.compiler.fork=true -Dmaven.compiler.executable="D:\Environment\JDK\jdk-21.0.2\bin\javac.exe"` 验证。
