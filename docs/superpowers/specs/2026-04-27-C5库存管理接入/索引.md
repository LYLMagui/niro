# C5 库存管理接入索引

## 主题

接入 C5 库存列表 SDK，按 C5 扫货账号维护库存最新快照，并将库存管理前端页面从 mock 数据切换为真实后端接口。

## 当前状态

已落地。当前项目中 `niro-sdk` 已存在 C5 库存列表封装 `C5InventoryClient.getInventory()`，后端已提供库存刷新、库存查询和库存落库链路，前端 `InventoryManagement.vue` 已从 mock 数据切换为真实接口。

## 当前有效结论

- 本期只做“最新库存快照”，不保存每次刷新历史批次。
- 库存数据与 C5 扫货账号配置绑定，账号配置需要新增 `steamId` 字段。
- C5 库存刷新使用账号级 `c5AppKey` 和 `steamId`，固定 CS2 `appId=730`。
- 库存快照表使用 `account_id + asset_id` 作为唯一业务键。
- 每次刷新成功后，本次返回的库存 upsert 为 `IN_STOCK`，该账号历史存在但本次未返回的库存标记为 `REMOVED`。
- 前端库存页账号下拉使用 C5 扫货账号列表，库存卡片使用后端库存查询接口，不再使用 mock 数据。
- 本期不做库存上架、手续费计算、库存刷新历史批次、贴纸/宝石/样式子表拆分。
