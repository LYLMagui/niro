# 权限管理迭代第二阶段执行计划（可长期维护版）

最后更新：2026-03-21

## 0. 状态规范

- `未开始`：尚未开始实施
- `进行中`：已开始但未收口
- `已完成`：实现与自测已完成
- `阻塞`：因外部依赖或风险暂时无法推进
- `已锁定`：方案已确认，不作为开发任务推进

## 1. 摘要（状态：已锁定）

- 目标：在现有最小 RBAC 能力上，升级为可长期维护的“菜单 + 按钮 + 角色 + 分配”管理体系。
- 范围：不包含 Buff 模块改造；沿用现有 5 表模型（`sys_user`、`sys_role`、`sys_menu`、`sys_user_role`、`sys_role_menu`）。
- 交付：独立权限管理页、菜单/按钮/角色完整 CRUD、角色绑定菜单/按钮、用户角色批量追加分配、权限码三段式治理（非 Buff 全量迁移）。
