# 菜单样式重做 实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 将左侧菜单重新调整为贴近目标图一的 ERP 风格：白底窄侧栏、直角选中块、左侧蓝条、一级二级菜单都更紧凑规整。

**架构：** 保留 `Layout.vue` 与 `SidebarItem.vue` 的现有递归菜单结构，不重写菜单系统。核心实现只放在 `Layout.vue`：统一侧栏展开宽度、重写 `.erp-side-menu` 作用域下的菜单项高度、图标区、激活态、二级缩进与 hover 规则；`SidebarItem.vue` 仅作为结构核对文件，默认不修改。

**技术栈：** Vue 3、TypeScript、TDesign Vue Next、Tailwind CSS、pnpm
