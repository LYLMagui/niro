# 菜单样式对齐 实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 将左侧菜单视觉对齐到图一的传统 ERP 风格：白底窄侧栏、一级菜单更规整、选中态保留浅蓝背景与左侧蓝色竖条、二级菜单缩进更紧凑。

**架构：** 保留现有 `Layout.vue` + `SidebarItem.vue` 的递归菜单结构，不重写菜单系统。实现重点放在 `Layout.vue`：收紧侧栏宽度、统一菜单容器留白、覆盖 TDesign 菜单项/子菜单的高度、字体、图标、选中态、hover 和层级缩进；`SidebarItem.vue` 仅在必要时做最小结构调整，默认不改业务逻辑。

**技术栈：** Vue 3、TypeScript、TDesign Vue Next、Tailwind CSS、pnpm
